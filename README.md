# 🏨 Hotel Booking & Management Dashboard

This project focuses on transforming a specific raw dataset into a strategic management tool. The dashboard is built entirely using the provided hotel booking data, showcasing the full process of modeling, and visualization.

## 🚀 Project Overview

The dashboard provides a 360-degree view of hotel performance, focusing on three core pillars:

  * **Finance:** Revenue trends, tax analysis, and payment status tracking.
  * **Customer:** Demographics, loyalty levels, and behavioral insights.
  * **Operation:** Occupancy rates, cancellation analysis, and room management.


## 📊 The Dashboard Structure

The report consists of three specialized pages:

1.  **Finance:** Strategic financial KPIs and revenue distribution.
2.  **Customer:** Insights into guest preferences and loyalty.
3.  **Operation:** Operational efficiency and booking channel performance.

## 📂 How to Access the PBIX File

Due to the dataset size and high-resolution visuals, the `.pbix` file is hosted in the **Releases** section of this repository.

1.  Navigate to the [**Releases**](https://github.com/BeyzaNurSarikaya/hotel-analytics-power-bi/releases) page.
2.  Download the latest version of `hotel_management_dashboard.pbix`.
3.  Open with **Power BI Desktop**.
